Dig at the desk.

Selecta is a Mac app too. Brief your AI and the set lands on a rail, with its tempo and key drawn underneath. Flip through your crate, drag records in, and hear it in Music before anything is saved.

  • The crate. Your library as records in a bin. Flip through, read the facts, drag one onto the set.
  • The rail. Every join says its tempo step and key move in plain words. Never a score.
  • Listen. Music plays the draft, AutoMix and all, and your edits follow along.
  • Save is yours. The AI can shape the draft. Only your button writes to Music.

Early days: no installer yet. Build it from source

You need a Mac with Node 22 and Rust. Install the engine, then Selecta, let it measure your library, and hook it up to your assistant. 

git clone https://github.com/Jonas-Ross/metrognome.git
cd metrognome && cargo install --path crates/metrognome-cli

git clone https://github.com/Jonas-Ross/selecta.git
cd selecta && npm install && npm run build
node dist/index.js refresh
node dist/index.js enrich && node dist/index.js enrich --source analysis
node dist/index.js setup --apply

setup registers Selecta with Claude Desktop and Claude Code. Any other MCP client can run node /absolute/path/to/selecta/dist/index.js as a stdio server.

For the Mac app, run npm run desktop in the selecta folder. It needs the Claude Code CLI, signed in.

Apple allows about 20 preview lookups a minute, so a big library takes a few hours to measure. Stop it whenever; it picks up where it left off.
